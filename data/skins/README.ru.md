# Mugen Heartbeat — пользовательские скины

Эта папка предназначена для **пользовательских/community-скинов**.

Встроенные скины, например **Bio Monitor** и **Heartbeat Lite**, поставляются
вместе с Mugen Heartbeat и хранятся отдельно в папке плагина. Поэтому здесь их
нет — это нормально.

## Установка пользовательского скина

Каждый скин кладётся в отдельную папку:

```text
skins/
└─ my-skin/
   └─ skin.json
```

После этого открой свойства источника Mugen Heartbeat в OBS и нажми
**«Обновить скины»**.

Если пользовательский скин имеет тот же `id`, что и встроенный, пользовательская
версия получает приоритет. Это позволяет локально тестировать изменённый вариант
скина, не трогая установленные файлы плагина.

## Создание собственного скина

Смотри:

- `SKIN-FORMAT.ru.md` — описание формата на русском
- `SKIN-FORMAT.md` — описание формата на английском

English version of this README: `README.md`.

Эти файлы документации обслуживаются Mugen Heartbeat и могут обновляться вместе
с плагином. Папки твоих собственных скинов плагин не изменяет.
