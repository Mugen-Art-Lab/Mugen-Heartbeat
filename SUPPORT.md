
# Support and bug reports

Please use GitHub Issues for reproducible Mugen Heartbeat bugs.

A useful report should include:

- Mugen Heartbeat version;
- OBS Studio version;
- Windows version;
- wearable / heart-rate sensor model;
- connection or heart-rate-sharing mode used on the device;
- Bluetooth adapter model when known;
- whether the problem also occurs in manual BPM test mode;
- exact reproduction steps;
- expected result and actual result;
- relevant OBS log.

For BLE, loading, reconnect or rendering problems, the OBS log is especially
important.

In OBS, use **Help → Log Files → View Current Log** or upload the current log
after reproducing the problem.

Do not include passwords, tokens or unrelated private information in logs or
screenshots.

Hardware compatibility reports are welcome even when nothing is broken. Please
state clearly whether live BPM, reconnect and a short OBS restart test were
successful.
