
# AI development disclosure

Mugen Heartbeat was developed by Mugen Art Lab with substantial assistance from
OpenAI ChatGPT.

AI assistance was used for parts of:

- code generation and refactoring;
- debugging and investigation;
- build and release tooling;
- documentation and translation;
- implementation brainstorming.

Project direction, architecture choices, feature selection, real-device testing,
visual evaluation, acceptance/rejection of generated changes, licensing choices
and release responsibility remain with Mugen Art Lab.

AI-generated or AI-assisted changes are treated as implementation material to be
reviewed and tested, not as an independent project author or maintainer.
